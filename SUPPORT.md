# Support

## How to get help

- **Bug / question / feature request:** open a GitHub issue using
  the [issue templates](.github/ISSUE_TEMPLATE/).
- **Security issue:** see [SECURITY.md](SECURITY.md). **Do not** open
  a public issue.
- **Discussion / "how do I..." questions:** start a
  [GitHub Discussion](https://github.com/lefthral/ai-era-identity-intelligence-platform/discussions).

## Response time

This is a portfolio / open-source project maintained in spare time.
There are no SLAs.

- Bug triage: within 7 days.
- Pull request review: within 14 days.
- Security disclosures: within 72 hours (see SECURITY.md).

## What this project is

A free-tier-deployable, end-to-end AI-fraud-detection demo built
around the documented Arup ($25.6M, Jan 2024) and Singapore ($499K,
Mar 2025) deepfake wire-fraud incidents. See `README.md` and
`docs/research_brief.md`.

## What this project is NOT

- Not a production banking system.
- Not a substitute for your bank's fraud controls.
- Not financial advice.
- Not certified for any regulatory regime (PCI-DSS, SOC 2, etc.).
